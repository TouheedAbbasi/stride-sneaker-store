# STRIDE: Move Different

A modern, high-conversion storefront for STRIDE, a premium athletic and lifestyle sneaker brand. Built with a bold visual style, scroll storytelling and smooth animations.

🔗 **Live demo:** https://stride-move-different.netlify.app/

## Features
- Responsive layout for mobile, tablet and desktop
- Scroll storytelling and animations on desktop
- Clean product-focused sections and call-to-actions
- SEO and social share meta tags
- Auto-deployed on Netlify from GitHub

## Tech Stack
HTML, CSS, JavaScript (apni asli stack yahan likho, jaise React / Vite / Tailwind)
